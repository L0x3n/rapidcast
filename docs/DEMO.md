# RapidCast demo production

The [final public edit](https://www.youtube.com/watch?v=r1Yl0Qw2ghU) has no narration. It uses original synthesized electronic music at 120 BPM, actual application captures, animated feature captions, directional transitions and an audio-reactive waveform. The duration is 157 seconds at 1920x1080 and 30 fps, with H.264 video and stereo 48 kHz AAC audio. It is linked from the [submitted project](https://devpost.com/software/rapidcast).

The persistent SIMULATOR + LOCAL TEST FOOTAGE and ENGINE BETA labels remain visible. The AI endpoint is a fixed-response test fixture. Local rendered frames and recordings demonstrate the workflow, not real Twitch delivery, model quality or model latency. The ten-minute statistics image records 720 simulator messages and one visible trigger. No real audience metrics are claimed.

The music is generated by `scripts/demo/music.py` from synthesized oscillators and deterministic noise. It uses no sampled tracks, third-party music or voice. The application source and generated submission material use this repository's MIT license. System font files are read from Windows for rendering; copied temporary font files stay under ignored out/demo and are not redistributed.

## Reproduce the edit

This optional media tooling needs Python with Pillow and NumPy in addition to the application's documented Node/npm setup. It uses the bundled ffmpeg-static executable by absolute path. Native capture runs in isolated temporary profiles under ignored out/demo, without Twitch login, physical capture devices or a real model. The setup smoke selects only its own test window.

Run native capture commands sequentially, after `npm ci` and `npm run build`:

```powershell
node scripts/demo/record-ui.mjs ai
node scripts/demo/record-ui.mjs widgets
node scripts/demo/record-ui.mjs setup
npm run smoke:stats:long
Copy-Item -LiteralPath out/stats-smoke -Destination out/stats-smoke-long -Recurse
npm run smoke:packs
python scripts/demo/render.py
```

The copy command assumes out/stats-smoke-long does not already exist; keep an existing verified long run instead of nesting or overwriting it. The renderer reads the captured app JPEG frames, native smoke screenshots/MP4s, release verification record and actual Git history. The test launcher can display the Electron wrapper version in its footer; the portable application is validated separately at the tagged release.

The finished file is `out/demo/RapidCast-demo-music.mp4`. The render plan and source are in scripts/demo; transient profiles, image sequences, WAVs and intermediate videos remain ignored. Capture-generated UI events are actual local test actions. Edited cuts and held frames do not imply real-model speed.

## Verification

The final MP4 is decoded completely with the bundled FFmpeg. Confirm the 157-second duration, H.264 1920x1080 30 fps video, AAC stereo audio, visible disclosure/feature captions and no clipped audio peaks. The final mux reads only the synthesized soundtrack for audio; all application/source clip audio is discarded. Inspect frames at chapter boundaries and during transitions before uploading.
